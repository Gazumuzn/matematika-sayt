# Тренажёр по математике

Сайт для занятий по «Тренажёру по математике для подготовки к ЕНТ» (И. П. и С. Т. Рустюмовы):
учебник по блокам, доска для графического планшета, домашние задания с загрузкой работ,
проверка работ пером, опыт, уровни и награды.

- Сайт: статические файлы на GitHub Pages (этот репозиторий).
- Данные: Supabase (аккаунты, база, закрытое хранилище файлов).
- Сканы книги и ответы в репозиторий **не входят**: они лежат в закрытом хранилище Supabase,
  их видят только вошедшие пользователи, ответы — по правилу, которое задаёт учитель.

## Аккаунты

Регистрации нет. Аккаунт учителя создаётся один раз при установке, учеников создаёт учитель
(раздел «Ученики»). Вход по логину и паролю.

## Структура

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс |
| `board.js` | доска (нажим пера, ластик, линия, окружность) |
| `api.js` | работа с Supabase |
| `stats.js` | опыт, уровни, награды |
| `config.js` | адрес проекта Supabase и публичный ключ (не секретный) |
| `book.json` | оглавление книги: главы, параграфы, блоки |
| `supabase/migrations` | таблицы и правила доступа (RLS) |
| `supabase/functions/admin-users` | создание, сброс пароля и удаление учеников (только учитель) |

## Обновить базу или функцию

```
npx supabase db push
npx supabase functions deploy admin-users
```
